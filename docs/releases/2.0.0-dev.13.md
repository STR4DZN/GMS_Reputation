# 2.0.0-dev.13 — Players originais e novo Mestre

Versão de desenvolvimento para atualizar o módulo e testar no Foundry VTT v13.

- Restaura a visão dos Players da dev.70.13, incluindo templates, rótulos, composição focal, cores, efeitos, animações, fichas de detalhes e carregamento de retratos.
- O único acréscimo é a pesquisa de NPCs por nome/grupo.
- Remove o sistema de paletas por NPC/grupo, seus controles, presets, persistência, herança e integração com histórico/undo.
- Campos antigos de paleta deixam de participar do modelo; histórico anterior e dados de reputação são preservados.
- Mantém o painel novo do Mestre: edição direta, matriz, lotes, protocolos, imagens, histórico e desfazer/refazer.
- Isola CSS e nomes de animação entre as duas visões.
- Pacote verificado e reproduzível, com manifesto e SHA-256 anexados.

## Atualizar

Feche o World e faça backup dos dados. No gerenciador de módulos do Foundry, verifique as atualizações ou instale utilizando o link do manifesto.

Manifesto para instalação e futuras atualizações:

https://raw.githubusercontent.com/STR4DZN/GMS_Reputation/main/module.json

O ZIP contém `module.json` na raiz: para instalação manual, extraia em `Data/modules/gms-reputation/`.
